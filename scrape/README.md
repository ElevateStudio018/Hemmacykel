# Skrapat från hemmacykel.se (2026-10-28)

Råtext från den gamla sajten, sparad som referens. Den nya sajten byggs från `scripts/build.py`.

- `index.md` – startsidan (serverrenderad text)
- `integritetspolicy.md`, `villkor.md`, `cookies.md` – juridiska sidor
- `cyklar-raw.json` – annonserna på /cyklar som de såg ut (laddas med JavaScript på originalet)

Omdömena laddas live från Google på originalet. Vid skrapningen visades 5.0 i betyg och 13 omdömen;
texterna finns i `REVIEWS` i `scripts/build.py`.

Bokningen (/boka) hade tre steg: tjänst + cykeltyp, tid (förmiddag/eftermiddag per dag) + adress, kontaktuppgifter.
Tjänster: Punktering 299, Däckbyte 349, Bromsjustering 199, Byte av bromsvajer 249, Byte av bromsklossar 249,
Kedjebyte 299, Övrigt / vet inte. Paket: Cykelcheck 499, Hemmaservice 749, Flera cyklar (2 st) 899.
Cykeltyp: Vanlig, Elsparkcykel (+100), Elcykel, Lådcykel, Tandem, Trehjuling/specialcykel, Fatbike (+50).
